主题

切换立即生效，无需重启。第三方主题与注入脚本等同可信代码。

外部心跳

Master 每 5 分钟向你配置的地址发一次 GET，用于让第三方监控（healthchecks.io / Uptime Kuma 等）在 Master 整体失联时报警。地址在「外部与高级」分组的 heartbeat_url 里配置。

数据库备份

备份用 VACUUM INTO 在线生成一致快照，不需要停服。自动备份按下方「每日自动备份 / 备份时刻 / 保留份数」三项设置每日执行一次，只保留最新的若干份。

备份文件含全部令牌哈希与会话，请与 master.key 分开保存（本目录权限 0700）。
